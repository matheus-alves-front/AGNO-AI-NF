---
name: build-workflow
description: Workflow for building software from scope to implementation.
---


Use this for new features or new products.

## Mandatory sequence
1. Scope
2. Technical spec with acceptance criteria
3. Architecture
4. Checklist / execution phases
5. Implementation of the current phase
6. Review + QA

## Rule
Do not jump directly from vague idea to code.

## Output contract
At each stage, produce a clear artifact before moving on.
