# Quick Start

## Goal
Drop this package into the root of a repository and use it from VS Code + Codex.

## What Codex reads
- `AGENTS.md`
- `.codex/config.toml`
- `.codex/agents/*.toml`
- `.agents/skills/*/SKILL.md`

## First use
1. Extract this package in the repository root.
2. Open the repo in VS Code.
3. Make sure the project is trusted.
4. Start Codex chat.
5. Use one of the core skills:
   - `$ticket-workflow`
   - `$build-workflow`
   - `$stack-workflow`
