# Subagents

## architect
Use for planning, touched-area mapping, architecture fit, and implementation sequencing.

## developer
Use for actual implementation after the plan is clear.

## reviewer
Use for an independent audit of scope, design fit, and regressions.

## qa
Use for acceptance criteria validation, user scenarios, and test thinking.

## product-owner
Use before coding when the request is still fuzzy and needs explicit requirements.

## frontend-specialist
Use for React / Next / CSS / Tailwind / shadcn / UI architecture and fidelity.

## mobile-specialist
Use for Expo / React Native flows, navigation, device constraints, and mobile UX.

## ai-systems-specialist
Use for LangChain, LangGraph, Agno, RAG, memory, MCP, and multi-agent systems.

## stack-researcher
Use when a stack or version question requires official docs, migration notes, and reusable conventions.
