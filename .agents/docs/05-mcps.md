# MCP Guidance

This package is MCP-ready, but MCP configuration depends on your local environment.
Edit `.codex/config.toml` and add only the MCP servers that matter for the repository.

## Suggested MCP sets
### Work / company code
- Linear
- docs / Context7
- Git tooling
- Slack bridge if available

### Build / product work
- Figma
- browser / devtools
- docs
- database tools when needed

### Stack research
- official docs
- migration-guide sources
- docs / Context7

## Rule
Start with few MCPs. Add more only when they remove a real manual loop.
